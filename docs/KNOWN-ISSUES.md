# Desop 已知问题

## 当前版本 (0.2.0)

### 功能限制

| 问题 | 影响 | 工作区 | 优先级 |
|-----|------|--------|-------|
| 全局菜单只显示前台窗口标题 | 无法访问应用内部菜单 | 使用应用自身的菜单栏 | S3 |
| 灵动岛事件需要第三方推送 | 无法直接显示系统通知 | 使用本地 API 推送事件 | S3 |
| 系统电量状态显示 unknown | 无法读取电池数据 | 暂不启用电量显示 | S2 |

### 兼容性问题

| 问题 | 影响 | 工作区 |
|-----|------|
| Windows 10 某些版本模糊效果降级 | 使用半透明替代 |
| 高 DPI (300%+) 未充分测试 | 按比例缩放，可能不完美 |
| 混合 DPI (不同缩放比) 未充分测试 | 主屏优先 |

### 性能

| 问题 | 影响 | 工作区 |
|-----|------|
| 空闲 CPU 使用率待实机验证 | 预期 < 1% |
| Dock 图标放大帧率待实机验证 | 预期 ≥ 55 fps |
