# Desop 支持矩阵

## Windows 版本支持

| Windows 版本 | 状态 | 说明 |
|-------------|------|------|
| Windows 10 22H2 | ✅ 支持 | 完整功能 |
| Windows 10 21H2 | ⚠️ 部分支持 | 某些 DWM 功能降级 |
| Windows 10 1809 | ⚠️ 部分支持 | 毛玻璃效果降级为半透明 |
| Windows 11 22H2 | ✅ 支持 | 完整功能（亚克力效果） |
| Windows 11 23H2 | ✅ 支持 | 完整功能（亚克力效果） |

## 架构支持

| 架构 | 状态 | 说明 |
|-----|------|------|
| x64 (Intel/AMD) | ✅ 支持 | 完整功能 |
| ARM64 (Windows on ARM) | ⚠️ 测试中 | 理论支持，需实机验证 |

## DPI 缩放支持

| 缩放比例 | 状态 | 说明 |
|---------|------|------|
| 100% | ✅ 支持 | 完整功能 |
| 125% | ✅ 支持 | 自动缩放 |
| 150% | ✅ 支持 | 自动缩放 |
| 200% | ✅ 支持 | 自动缩放 |

## Python 版本支持

| Python 版本 | 状态 |
|------------|------|
| 3.10 | ✅ 支持 |
| 3.11 | ✅ 支持 |
| 3.12 | ✅ 支持 |
| 3.13 | ✅ 支持 |

## 构建环境

| 环境 | 状态 |
|-----|------|
| Windows 10/11 | ✅ 支持 |
| macOS (交叉编译) | ⚠️ 实验性 |
| Linux (交叉编译) | ⚠️ 实验性 |

## 限制

- 不支持 Windows 7/8
- 不支持 Server 版本（未测试）
- ARM64 构建需要 Windows 11 ARM64 环境
